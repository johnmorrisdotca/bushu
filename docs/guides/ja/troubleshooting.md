## 空の結果と情報がない場合

| 結果 | 意味 |
| --- | --- |
| `kanjiForRadicals`が`[]` | 未選択、不明なキー、または全ての部品を含む漢字がありません。 |
| `radicalName` / `radicalNameEntry`が`null` | そのキーに対応する部首名がありません。 |
| `radicalNameForShape`が`null` | その表示形に対応する名前がありません。 |
| `strokesOf`が`null` | 同梱の画数索引にない文字です。 |
| `usableRadicals`に選択済みのキーだけが残る | 現在の候補から追加できる部品がありません。取り消しはできます。 |

表示形を検索関数に渡す前に、RADKFILEのキーを確認します。標準の選択画面は、入口で対応するキーや形を扱います。同じ阝だからといって、保存する邦と阡を1つにまとめないでください。

## 読み込みと表示

`loadBushuData`を待ってからデータを渡します。importの失敗は、ページ側で例外として扱います。要素のデータも非同期なので、作成直後に読むのではなく、標準の読み込み・エラーイベントと仕様に記載した値を使います。狭い表示や初期値の120件では、`matches()`の全てを表示しないことがあります。実際の要素へ表示し、取り除くときは破棄します。
